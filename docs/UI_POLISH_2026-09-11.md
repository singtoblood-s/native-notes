# UI refinement — 11 September 2026

## แนวทาง

จัดหน้าคลังสมุดและหน้าเขียนให้ใช้ระบบภาพเดียวกัน: พื้นขาว/เทาอ่อน
ข้อความสีเข้ม และสีน้ำเงินสำหรับปุ่มหลักและสถานะเลือก กระดาษและปกสมุด
ยังเป็นจุดเด่นของแอป ใช้ฟอนต์ระบบเพื่อเปิดได้รวดเร็วและทำงานออฟไลน์
โดยไม่เพิ่ม dependency หรือดาวน์โหลดฟอนต์จากภายนอก

## รายละเอียดที่เปลี่ยน

- **คลังสมุด:** แถบนำทางด้านซ้ายตั้งแต่ 900px ขึ้นไป และแถบด้านล่างบนจอเล็ก
  แสดงชื่อหมวด จำนวนสมุด และปุ่ม New document ชัดเจน ช่องค้นหาแยกจาก
  ตัวเรียงลำดับและปุ่มสลับมุมมอง; พื้นที่รายการเลื่อนได้ภายในหน้าจอ
- **ปกและรายการ:** ปรับขนาดปก ระยะห่าง ตัวอักษรและข้อมูลจำนวนหน้า/วันที่
  ปกขยับเล็กน้อยเมื่อ hover และโฟกัส; Favorites และเมนูสมุดกดแยกจากปก
  ในมุมมองรายการ ปุ่มการกระทำวางเรียงแนวนอน
- **สถานะว่าง:** ใช้ภาพกระดาษขนาดเล็กที่วาดด้วย CSS พร้อมข้อความอธิบาย
  การสร้างสมุด การค้นหาไม่พบ และ Favorites โดยใช้พฤติกรรมเดิมของแต่ละหมวด
- **หน้าเขียน:** เปลี่ยนหัวแถบสีน้ำเงินเข้มเป็นสีขาว ใช้ไอคอน SVG ในชุดเดียวกัน
  เพิ่มชื่อ Read, Pen, Highlight, Erase และ Line ใต้เครื่องมือ
  ปุ่มที่เลือกมีพื้นน้ำเงินอ่อนและเส้นกำกับ; สีหมึกและความหนาอยู่ในกลุ่มแยก
- **จอเล็ก:** เครื่องมือเลื่อนแนวนอนได้ ตัวเลือกสี/ความหนาอยู่แถวถัดไป
  แถบชื่อหน้าและเปลี่ยนหน้าแยกสองแถวเมื่อจอแคบมาก แผงข้อความเปิดจากด้านล่าง
  เมนู Insert อยู่ภายนอกแถวเลื่อน เพื่อไม่ถูกตัดขอบ
- **หน้าต่างและฟอร์ม:** ปรับ Sign in, New document, เลือกกระดาษ และ Settings
  ให้ใช้ระยะห่าง ปุ่ม ช่องกรอก และมุมโค้งร่วมกัน; ชื่อ Settings ใช้ Sync & backup
  เพื่อบอกงานที่ทำได้ชัดเจน ช่องกรอกบนมือถือมีตัวอักษรอย่างน้อย 16px
- **การเข้าถึง:** คงชื่อที่โปรแกรมอ่านหน้าจอใช้กับปุ่มและสถานะเดิม
  เพิ่ม focus ring ให้ลิงก์และ summary ของรายละเอียด และคง reduced-motion rule
  ที่ลด animation/transition เมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว
