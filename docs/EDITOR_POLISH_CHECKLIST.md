## ผลตรวจและวิธีใช้

สถานะ: ลงมือแก้แล้วใน workspace, build `2026.09.11.3` ยังไม่ได้ push หรือ deploy เว็บสาธารณะ

| ปัญหาเดิม | สิ่งที่แก้ | หลักฐานตรวจรับ |
| --- | --- | --- |
| เปลี่ยนหน้าแล้วยึกยัก | กรอบหน้าเท่ากัน, เก็บ DOM, เลือกหน้าหลังเลื่อนหยุด, screen coordinates, momentum, คง zoom ใน Page turn | Unit gestures และ browser ตรวจขนาด/DOM ทุกโหมด รวมกรณีภาพเล็กและกระดาษใหญ่ |
| อัปโหลด/วางรูปเข้าถึงยาก | Insert บน toolbar, เลือกหลายภาพ, drop, copy, clipboard read และช่อง Paste fallback | ทดสอบ native file chooser, copy/paste clipboard จริง, drop และ reload |
| เมนูสามจุดดูว่าง | แก้ CSS สีขาวบนขาว, วาง popup ในขอบจอ, Escape, aria-expanded | ตรวจภาพหน้าจอ desktop 1024×900 และ tablet 768×1024 |
| ต้องการ PDF และ New จากไฟล์ | PDF.js แปลงทุกหน้าเป็นพื้นภาพ เรียงตามต้นฉบับ; New Picture/PDF; เพิ่มหน้าในสมุดเดิม | PDF A4 portrait/landscape จริง และรูปโปร่งใส; schema version 2 |
| ส่งออกไม่ครบ | ส่ง PNG / PDF หน้าเดียว / PDF ทั้งสมุดด้วย renderer ลำดับชั้นเดียวกัน | เปิด PDF กลับด้วย pdf-lib และ Poppler; เห็นข้อความไทย ภาพ และลายเส้น; ขนาด A4 ถูกต้อง |

| ความทนทาน | Import เป็น transaction เดียว, จำกัดขนาดภาพ/หน่วยความจำ, ยกเลิก, ทิ้งผลเมื่อเปลี่ยนหน้า/บัญชี | Unit validation/save failure; PDF เสียและ PDF ใส่รหัสผ่านแสดงเหตุผล; ไม่มีหน้าครึ่งชุด |
| ออฟไลน์ | รวม PDF worker, CMaps, fonts, WASM; แก้ static-cache Vary mismatch | โหลด production build, ปิดเครือข่าย, reload และรัน import/write/export ใหม่ผ่าน |

ขั้นตอนใช้งาน:
1. Documents → New → Picture หรือ PDF → Choose files: สร้างสมุดพร้อมหน้าที่เขียนทับได้
2. ในสมุด → ปุ่ม Insert (⊕) → Picture from device / Import PDF pages / Paste
3. ลากไฟล์ภาพลงกระดาษ; ถ้าเป็น PDF จะเพิ่มหน้าในสมุดปัจจุบัน
4. ใช้ปากกา/ไฮไลต์เขียนทับได้ทันที พื้น PDF เต็มหน้าจะไม่ถูกลากโดยไม่ตั้งใจ; เลือกภาพใน Text ก่อนหากต้องการปรับพื้นภาพ
5. กดค้างบนกระดาษ → Paste picture / text หรือใช้ Ctrl/Cmd+V; Copy ภาพได้จาก Text → เลือกรูป → Copy image
6. ปุ่ม Export (↥) หรือเมนู ⋯ → Export PDF / picture → เลือกหน้า/ทั้งสมุด
7. หาก browser ไม่ให้สิทธิ์ clipboard จะมีช่องให้กดค้างแล้วเลือก Paste ของระบบ หรือเลือกไฟล์แทนได้

คำสั่งตรวจซ้ำ (จาก `webApp`):
```powershell
npm test
npm run build
npx playwright install chromium
npm run test:browser
```
บน Windows ที่ติดตั้ง Edge อยู่แล้ว ไม่ต้องดาวน์โหลด Chromium:
```powershell
$env:QA_BROWSER_CHANNEL='msedge'
npm run test:browser
```
ตรวจ production offline: เปิด `npm run preview -- --port 4176` อีก terminal แล้วรัน:
```powershell
$env:QA_BROWSER_CHANNEL='msedge'
$env:QA_URL='http://127.0.0.1:4176/native-notes/'
$env:QA_OFFLINE='1'
npm run test:browser
```
Browser test สร้างข้อมูลจำลองใน browser context ใหม่ ใช้ endpoint `qa.invalid` และไม่อ่านสมุดจริง ผลภาพ/ไฟล์อยู่ใน `webApp/test-results/editor/` ซึ่งไม่เข้า Git

## ข้อจำกัดที่แจ้งตรงตามสิ่งที่ทำ

- PDF นำเข้าเป็นภาพด้านยาวสูงสุด 2,000 พิกเซลต่อหน้า ไม่เก็บเวกเตอร์/ฟอร์ม/ลิงก์หรือไฟล์ต้นฉบับ; PDF ใส่รหัสผ่านต้องปลดรหัสก่อน
- PDF รักษาขนาดหน้าต้นฉบับในช่วงด้านละ 240–7,500 points; แสดงข้อความผิดพลาดสำหรับขนาดนอกช่วง
- ครั้งละสูงสุด 100 หน้า, PDF 50 MB ต่อไฟล์, รูป 12 MB ต่อไฟล์, ภาพที่เตรียมรวม 38 MB; หน้าจัดเก็บไม่เกิน 100 รูป/รวม 10 MB
- PNG/PDF ส่งออกเป็นภาพรวมหน้า ความละเอียดด้านยาวสูงสุด 2,400 พิกเซล; ลายเส้นต้นฉบับยังแก้ได้ใน NotePad/backup
- ข้อความที่ paste จะเพิ่มใน Typed note และแสดงจากด้านบนของหน้า แก้ได้ใน Text; ยังไม่ใช่กล่องข้อความอิสระที่ย้ายตำแหน่งได้ ข้อความยาวเกินขอบหน้าเก็บใน backup แต่ไม่แสดงส่วนที่เกินใน PDF/PNG
- Browser QA ยืนยันการทำงานและข้อมูลในเครื่อง ไม่ได้วัด frame time/ความหน่วงของ Apple Pencil หรือ S Pen และไม่ได้ทดสอบ PDF ใหม่ข้ามสองเครื่องกับ production sync server
